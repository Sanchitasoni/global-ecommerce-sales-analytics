# Global E-Commerce Sales & Customer Analytics

## Project Overview

This project analyzes global e-commerce sales data to identify sales trends, customer behavior, product performance, regional performance, and profitability.

## Objective

The objective is to use data analytics and visualization techniques to generate useful business insights from e-commerce data.

## Dataset

Dataset Name: Global E-Commerce Sales & Customer Data

Source: Kaggle

Dataset File: global_ecommerce_sales.csv

The dataset contains 2,000 e-commerce transactions and 15 features.

## Tools and Technologies

- Python
- Pandas
- Matplotlib
- Streamlit

## Project Workflow

Dataset
→ Data Cleaning
→ Data Analysis
→ Data Visualization
→ Business Insights
→ Interactive Dashboard

## Analysis Performed

The project analyzes:

- Total Sales
- Total Profit
- Number of Orders
- Average Order Value
- Sales by Region
- Sales by Product Category
- Profit by Product Category
- Customer Segment Performance
- Monthly Sales Trends
- Top Products by Sales
- Data Quality

## Data Quality

The project checks for:

- Missing values
- Duplicate records
- Date formatting issues

## Dashboard

The Streamlit dashboard provides interactive filters for:

- Region
- Product Category
- Customer Segment

Users can use these filters to explore sales and business performance.

## How to Run the Project

Install the required packages:

pip install -r requirements.txt

Run the Streamlit application:

python -m streamlit run app.py

## Project Files

- app.py — Streamlit dashboard and analysis code
- global_ecommerce_sales.csv — Dataset
- requirements.txt — Python dependencies
- README.md — Project documentation
